# WhatsApp Accesible

Cliente de escritorio de **WhatsApp para Windows, pensado para personas ciegas**,
creado por **Eduardo Petrini**. Totalmente manejable por teclado y optimizado para
lectores de pantalla (NVDA).

## Descargar

Andá a la sección **[Releases](../../releases)** y bajá el archivo
`WhatsAppAccesible_vX.Y.Z.zip` de la última versión. Descomprimilo donde quieras y
ejecutá `WhatsAppAccesible.exe`. No requiere instalación.

## Actualizaciones automáticas

La aplicación revisa sola si hay una versión nueva al iniciar y también desde
**Ajustes → Buscar actualizaciones**. Cuando hay una, te avisa y, si aceptás, la
descarga y se reinicia sola. Tus datos (sesión, historial, audios) no se tocan.

## Notas

- Vinculás tu teléfono una vez con un código, como en WhatsApp Web.
- Tus datos quedan en la carpeta `data/`, al lado del ejecutable. Es tuya y no se
  comparte.
