## ✨ Por qué este cliente

WhatsApp dejó de tener una app nativa accesible en Windows. Este proyecto la reemplaza:
en vez de meter la web dentro de una ventana, habla el **protocolo nativo de WhatsApp**
por debajo, así que es **liviano, rápido de abrir y estable**. Y cada detalle está pensado
para el teclado y el lector de pantalla, no para el mouse.

## 🚀 Qué podés hacer

- **Mensajes de texto** — enviar, recibir, responder, citar, reenviar, editar, eliminar, reaccionar.
- **Notas de voz** — grabar (con pausa y cancelar), enviar y reproducir, con control de
  velocidad manteniendo el tono, y reproducción encadenada de audios consecutivos.
- **Archivos** — imágenes, videos, documentos y stickers: recibir, abrir, guardar.
  Enviar arrastrando o **pegando archivos** en el cuadro de escribir (Ctrl+V).
- **Grupos** — crear, administrar (nombre, descripción, participantes, roles, enlaces de
  invitación, aprobación de nuevos miembros, "solo admins"), y un **menú por participante**
  (mensaje privado, mencionar, info, copiar número).
- **Encuestas** — crear, votar y ver resultados en vivo.
- **Estados** — ver y publicar (texto, foto, audio).
- **Organización** — fijar, silenciar, archivar, marcar como no leído, favoritos, buscar
  dentro del chat, exportar un chat completo a `.zip`.
- **Privacidad** — última vez, en línea, foto, estados, confirmaciones de lectura, grupos.
- **Compartir contacto**, **mensajes temporales**, **cambiar tu nombre visible**, y más.

## ♿ Accesibilidad de verdad

- Probado con **NVDA, JAWS y Narrador**.
- Todo se alcanza y se opera **con el teclado**; cada acción avisa su resultado por voz.
- Separadores de **día** y de **mensajes no leídos**, con salto directo a lo no leído.
- Lectura de comentarios de archivos (sinopsis de libros, etc.).
- Modo opcional **"sin voz en segundo plano"**: cuando la app no está en primer plano,
  te guiás solo por los sonidos, sin interrupciones habladas.

## ⬇️ Descargar e instalar

1. Entrá a **[Releases](../../releases/latest)** y bajá `WhatsAppAccesible_vX.Y.Z.zip`.
2. Descomprimí la carpeta donde quieras.
3. Ejecutá **`WhatsAppAccesible.exe`**. No requiere instalación.
4. La primera vez, vinculás tu teléfono con un código (como en WhatsApp Web).

## 🔄 Actualizaciones automáticas

La aplicación revisa sola si hay una versión nueva al iniciar, y también desde
**Ajustes → Buscar actualizaciones**. Cuando hay una, te avisa y, si aceptás, la descarga
y se reinicia sola. **Tus datos (sesión, historial, audios) no se tocan.**

## ⌨️ Atajos útiles

| Atajo | Acción |
|---|---|
| **Enter** | Abrir / reproducir el mensaje seleccionado |
| **Alt+R / Alt+E** | Responder / editar el mensaje |
| **Alt+Q** | Grabar audio (de nuevo para enviar) |
| **Alt+↓** | Ir a los mensajes no leídos |
| **Alt+1…0** | Leer los últimos mensajes sin moverte del cuadro |
| **Ctrl+F / F3** | Buscar dentro del chat / siguiente coincidencia |
| **Ctrl+G** | Guardar el archivo seleccionado |
| **Ctrl+V** | Pegar y enviar archivos copiados |

## 🔒 Tus datos

Todo tu estado (sesión, historial, audios, ajustes) vive en la carpeta **`data/`**, al lado
del ejecutable. Es tuya y no se comparte. Podés copiar la carpeta completa a otra PC y seguir
sin volver a vincular.
